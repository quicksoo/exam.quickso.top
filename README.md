# exam.quickso.top

QuickSo 考试时钟，适合教室大屏、监考投屏。原生 HTML / CSS / JavaScript，无依赖、无构建步骤。

## 使用

在本目录运行 `node server.mjs`，访问 <http://127.0.0.1:4174>。可通过 `PORT` 环境变量修改端口。也可以直接双击 `index.html`。

点击「考试设置」，填写考试名称、开始和结束时间及考试须知（每行一条），保存后显示本场考试。支持跨天考试、深色主题，以及最后 5 / 10 / 15 分钟用醒目颜色强调。

页面自动切换距开考、距结束及已结束状态。时间基于设备系统时间，每次更新都重新计算剩余时间，避免计时器累积误差；请在使用前校准设备时间，保持设备唤醒、页面打开。设备休眠或浏览器暂停页面期间无法保证即时提醒，恢复页面后会重新计算并补发结束提醒。

点击「启用结束提示音」或保存启用声音的设置后，可通过「试听」确认设备音量。考试结束自动弹出提醒，提示音响四组；点击确认或 Esc 可停止。每次重新打开页面都需点击启用声音，浏览器会限制未经用户操作的自动播放。打开一个已经结束的考试不会补响。

考试日期、起止时间与总时长跟随考试名称显示，窄屏会自动换行。竖向进度条位于当前时间卡片内部右侧，与边缘保持间距；顶部为开始时间，底部为结束时间，轨道从初始状态就由上至下呈绿、黄、红渐变。箭头随考试推进从上往下移动，经过的部分变灰；临近结束强调设置控制箭头变红，轨道保持渐变。左侧细刻度标出一半时长以及剩余 30、10 分钟的位置，标签仅显示对应的分钟数字。例如 60 分钟考试显示 30、10，120 分钟考试显示 60、30、10。重合刻度合并显示，达到或超过总时长的固定分钟刻度不显示。不再单独显示倒计时数字和起止标签，结束提醒保持可用。

「全屏显示」使用浏览器全屏功能，Esc 退出；具体支持情况由浏览器决定。桌面全屏将标题与看板整体居中，限制内容宽度与卡片高度，为标题上方保留留白。全屏时隐藏顶部品牌、导出入口及声音与存储辅助说明，保留退出全屏和考试设置按钮，并在卡片下方显示「exam.quickso.top · 以本机时间为准」。需要导出或试听声音时，可先退出全屏。

## 离线导出

保存设置后点击「导出离线版」，下载包含本场设置的单个 HTML。样式、逻辑及合成提示音全部内置，不请求网络资源；复制到其他电脑，双击打开即可使用。离线版同样支持编辑、全屏、结束提醒和再次导出。

设置仅保存在当前浏览器的本机存储中。每次导出拥有独立存储标识，避免不同考试相互覆盖。浏览器禁用本机存储时仍可使用和导出，但刷新后不会保留改动。设置面板内尚未保存的内容不会进入导出文件。

## 部署

将 `index.html`、`robots.txt`、`sitemap.xml` 放到 `exam.quickso.top` 的静态站点根目录即可，无需部署 Node 服务。支持 `?embed=1` 精简品牌栏，方便 QuickSo 聚合页 iframe 嵌入；服务器应允许可信父站嵌入，并为 iframe 配置 `allow="fullscreen"` 以支持全屏。聚合页入口为 `https://quickso.top/?site=exam`。

页面包含标题、描述、canonical、Open Graph、Twitter Card 及 WebApplication JSON-LD；分享图片复用 QuickSo 正式品牌资源。嵌入页与查询参数页规范化到 `https://exam.quickso.top/`。离线导出文件标记为 `noindex,nofollow`。上线后可向搜索引擎提交 `https://exam.quickso.top/sitemap.xml`。

## 验证

运行 `node verify.mjs` 检查页面脚本语法，以及计时边界、延迟恢复、结束提醒、表单校验、跨天考试、本机存储降级和导出配置转义。检查使用最小 DOM 模拟环境，实际排版、浏览器全屏及音频设备效果仍需在浏览器中预览。`node --check server.mjs` 检查预览服务器。

页面的脚本和样式均在 `index.html` 内，以保证单文件离线使用。
